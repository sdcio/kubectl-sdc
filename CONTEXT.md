# kubectl-sdcio

## Language

**Owner**:
The source that supplied the winning value of a configuration attribute: `running` (the device itself), `default`, or `<namespace>.<intentname>` (an intent).
_Avoid_: source, origin

**Blame tree**:
The configuration of a target where every leaf carries its **Owner**. It can be rendered as a tree or as one XPath line per leaf.
